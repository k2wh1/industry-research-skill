# 21｜论证架构与跨行业利润分配的强制复审（v2.11）

## 为什么需要这项规则
半导体总稿有主线，却多次停留在并列公司案例，未将“新增 AI 需求”系统传递至 GPU/ASIC、HBM、晶圆制造、先进封装、设备/材料及最终投资判断。还有 GPU/ASIC 成本边界与盈亏平衡公式不一致、旺季单年 ROIC 代理误用、射频/MEMS/光电子研究薄弱、EDA/IP 与 Fabless 章节重叠、正文大量重复“不等于/不能”而稀释积极判断。这些是**论证架构**问题，不是简单写长或润色能解决。

## 第一原则：先给报告一个可检验的总问题
- 对行业深度，先明确贯穿全文的核心争议，例如“本轮新增需求如何经由供给约束、替代能力、议价权和资本强度，改变行业链各方的增量经济利润？”这只是半导体示例，不是所有行业的固定结论。
- 主报告先建立可证伪的**产业总论点**、核心变量和分析范围；各专题必须贡献真实独立证据或反例，并向主报告回写**共同问题的答案**。不能用9家公司案例列表代替9个行业之间的推演。
- 针对行业的重要利润转移，建立双向成本/收入/利润传导桥：需求→订单→可交付产能→数量/ASP/mix→营业利润→营运资本/Capex→增量 ROIC/FCF→投资判断。每一跳写清前提和可能相反的结果；没有产品级利润披露时区分方向性推断与可量化测算。

## 逐专题统一的三条结论
每个 HIGH 专题结尾应从实证研究中回答：（1）谁创造价值，产品作用是什么、谁付钱、利润驱动和资本约束是什么；（2）谁获得了超额利润，凭什么具有定价/交付/成本优势，哪类竞争或经营证据挑战这个判断；（3）需求、价格、竞争、技术和资本周期中哪项变量会改变利润归属，什么证据可以证伪。
高优先级子领域不能用名称覆盖代替实质分析。研究范围内多个细分产品性质不同，须分开研究；如 MCU 与 RF、MEMS、光电子，不能凭 MCU 案例宣布全部满足。EDA 供应商的客户是芯片设计人员，EDA/IP 的许可及使用模式不能简单照搬 Fabless 芯片销售逻辑；有交叉时使用引用链接，而非重复完整章节。

## 证据 → 解释 → 财务 → 判断 → 反证
- 重要段落用完整逻辑链：**可核验事实（含对照）→ 作用机制及前提→量价/毛利/现金流/投入资本变化→有边界的主动判断→最强竞争解释→跟踪与证伪**。不能止于“不能推出”或堆砌注意事项。
- 区分相关与因果：季度收入上涨与毛利率变化同时发生，不证明单一因素造成毛利变化；要有管理层解释、独立比较、变动桥接和替代解释。使用“主要由于”必须具备相应来源或清晰的条件化推断。
- 产业利润分配必须区分绝对利润额、利润率、经济利润与 ROIC，不能把高毛利率直接当利润池占比。某环节议价改善也可能增加下游成本而降低其超额利润，应交叉核对。
- 单年高景气期 ROIC 只是当期指标：增加 3–5 年历史、跨周期现金回收、营运资本及新增资本投放；无法获得分部资本时明确只能比较集团代理，不得写“产品长期资本回报优势”。

## 数学模型与经营文字必须一致（硬约束）
- **先定义统一成本范围与时间长度再推导公式**。GPU 与 ASIC 示例：同一任务量 Q，C_G(Q)=F_G+c_G·Q，C_A(Q)=F_A+c_A·Q；若两者可比，盈亏平衡 Q*=(F_A−F_G)/(c_G−c_A)，分母为零或 Q*≤0 时不得报出有意义的正向替代临界点。原式 F_A/(c_G−c_A) 仅在 F_G=0 且其他前提满足时成立。
- 核对 CAPEX 是期初现金流还是按相同期间折旧/摊销，不能同一项目把硬件购置现金和折旧同时重复计入成本。GPU 利用率、ASIC NRE、工艺更新、软件迁移、网络和能源、价格下降都应进入对应经济边界或作为显式缺口。
- 每个核心模型至少做单位、期间、边界、固定/变动成本、极端情景和负例测试；得出临界点之前检查符号与可行区间。测试脚本只能查登记完整性，真正公式和数值仍要独立复算。

## 投资判断不能停在“需要观察”
- 区分 **产业成长→企业盈利改善→增量经济利润→证券价格是否反映**。不强制虚构目标价，也不强制有无法获得的一致预期；但至少给出“何种经营改善可能形成预期差、需要多大变化才影响现金流、何时会失败”的条件判断或阐明何处还无法识别。
- 结束章节必须综合上游/下游的受益和受损，不只是各公司利好叠加。竞争性情景要指出可能的利润迁移、经济利润损失和投资含义。

## 编辑审查：不让口径限制压倒研究
- 口径定义原则上在首次出现处说明一次，统一放入方法附录；正文只保留会直接改变经济判断的限制。
- 对“不能、不等于、可能、需要观察”等句子做**人工语义审读**：若一句只否定错误推断，而没有给出证据支持的正面判断、替代研究或具体后续证伪条件，应补足或删改。**不设置词频硬阈值**，防止机械删掉必要的审慎表达。
- 附录放公式核对、统计口径和来源细节，正文围绕争议、经营机制和结论走；避免每轮返工只在末尾加新章。最终全文 review 时检查逻辑顺序、章节归属、重复与重要结论跨章矛盾。

## 新增研究资产与有限文档检查
- `argument_scope.csv`：主报告和实际 HIGH 专题的研究边界；没有跨专题的关联应有具体经济原因。
- `argument_chains.csv`：每项关键判断至少记录证据、机制、财务映射、反方解释、证伪条件与结论边界。
- `cross_sector_bridges.csv`：产业链跨环节价格、数量、成本和利润传导及竞争应对；不能靠简单箭头冒充经济测算。
- `model_logic_checks.csv`：模型的成本边界、固定/变动成本处理、期间/单位、公式复核与反例验证。

执行：

    python scripts/argument_logic_gate.py --scope outputs/argument_scope.csv --claims outputs/argument_chains.csv --bridges outputs/cross_sector_bridges.csv --models outputs/model_logic_checks.csv --report-type industry_full --out outputs/argument_logic_gate_result.json

关卡的 PASS **只代表登记内容格式和引用关系齐备**。它不阅读全文、不证明因果识别、不复算公式、也不能自动认定研究深度与正式定稿质量；实质研究判断必须审阅正文及模型，关键结论有实际证据支持后才可满足 v2.10 定稿协议。
