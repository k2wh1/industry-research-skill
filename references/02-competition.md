# 模块 2：竞争格局

## A. 价值链、利润池与议价权

- 画出上下游供货与客户关系，记录每个环节的产品/服务、付费单位、交付依赖、客户集中度。
- 优先比较相同周期的**毛利、营业利润、ROIC、自由现金流**；企业间会计口径不同必须标注。
- 利润池可用 `可比行业营业利润之和` 作为近似，但需说明公司跨行业营收、合并范围和重复计算限制。不得直接加总所有环节收入作为产业 TAM。
- 探讨瓶颈、替代、标准、规模效应、客户验证周期怎样决定利润分布，而不只是画一张链条图。

## B. 波特五力（每项给证据）

| 力量 | 证据/观察变量 | 结论 |
|---|---|---|
| 现有竞争 | 竞争者数量、产能利用率、价格行为、份额变化 | 强/中/弱，说明原因 |
| 潜在进入 | 投入资本、时间、认证门槛、许可、专利 | 新进入者威胁 |
| 替代威胁 | 替代方案性能、迁移成本、客户 TCO | 替代速度 |
| 客户议价 | 大客户集中、采购量、切换成本、自研 | 压价能力 |
| 供应商议价 | 核心设备/材料独供、交期、替代性 | 成本传导 |

五力结果与盈利能力关联，而非直接当作股票评级。

## C. 市场集中度

`CR4 = 同一市场前 4 家销售额（或统一定义的出货量）/同一市场总量`；CR8 同理。

算之前核验：

1. 竞争者是不是同一产品范围和价值链层级；
2. 分母市场是否覆盖全球/中国/特定用途；
3. 同一年度/财年或可合理对齐；
4. 收入口径、产能口径、出货口径是否一致；
5. 有无集团内部交易、合资企业重复、代工/自有品牌口径混用。

无完整市场份额数据时报告「未知」，可以给出区间估计但必须有计算来源；市场份额不能自动推断利润份额。

## D. 竞争位置与壁垒

按 `性能 / 成本 / 规模 / 良率 / 渠道 / 生态 / 知识产权 / 客户关系 / 交付质量 / 资本强度` 建立公司矩阵，筛选对本行业真正重要的维度。对每种壁垒回答：

- 如何产生超额利润？现有可验证证据是什么？
- 需要投入多久/多少资金才能追赶？
- 是否可能被技术范式、监管、客户自研、供应链改变所侵蚀？
- 当前壁垒归属公司、产品、客户关系还是行业周期？

**输出**：竞争者对照表、价值链利润图、CR计算或缺口、五力表、壁垒强弱和格局演变场景。
