# 模块 1：行业分析

## A. 产品、客户与支付链

1. 用两三句话说明行业解决什么问题、最终应用场景、产品边界与替代技术。
2. 画出技术/产品流、采购流和资金流：原材料/设备 → 制造/集成 → 渠道/平台 → 终端客户。
3. 区分 `使用者`、`选型者`、`采购者`、`付款者`；列交付物、计费单位、决策因素、切换成本。
4. 按主流产品/技术/用途/客户群分层，而非把所有细分子市场混为一个分母。

## B. 商业模式与单位经济

| 分析对象 | 应回答的问题 |
|---|---|
| 收入 | 销量 × ASP、订阅量 × ARPU、项目收入还是容量/调用量收费？ |
| 成本 | 原料、折旧、能源、研发、销售佣金，哪些固定/可变？ |
| 毛利 | 规模、价格、良率、产品结构、利用率如何影响？ |
| 现金流 | 预付款、应收、库存、资本开支、维护成本与现金转换？ |
| 客户价值 | ROI、降本增效、监管约束、技术性能、总拥有成本？ |

## C. 生命周期

- 划分技术萌芽、快速渗透、成熟、结构性调整/衰退（可对同一行业不同细分分开判断）。
- 采用渗透率、价格/性能曲线、采用者结构、替代率和供给扩张验证阶段。
- 不能仅因市场增速高就定义早期；新产品也可能替代存量市场，不产生等额新增 TAM。

## D. 规模、驱动与预测

至少采用一种自下而上模型并和公开行业口径交叉检验：

- `市场规模 = 出货量 × 平均售价`（分产品/地区/客户后求和）；
- `出货量 = 终端装机 × 单机配置 × 渗透率 × 替换频率`（根据产品适用调整）；
- `收入增速 ≈ 数量增速 + 价格增速 + 结构变化`（精确计算应含交互项；近似需标明）。

市场规模必须明确分母（收入/出货/装机/运算量），不要把上游芯片收入与下游整机收入相加。TAM/SAM/SOM 必须说明渗透率与可服务市场边界，不能与收入相互替代。

驱动树划分：需求端（终端景气/渗透/单机价值）、供给端（产能/良率/交付）、价格端（议价/周期）、结构端（产品组合/区域）、政策端（补贴/管制）。给出历史趋势与未来 1–3 年核心参数范围。

## E. 供需与周期

- **需求**：终端真实需求、客户采购、渠道销量、库存补货、延期需求，避免重复统计。
- **供给**：名义产能、有效产能、良率、稼动率、库存、扩产周期、设备与关键原料瓶颈。
- **价格**：现货/合约/挂牌/实际成交价格口径；价格弹性及传递滞后。
- **平衡**：`可用供给 = 期初库存 + 当期有效产出 + 进口 - 出口`，与终端消耗及期末库存变化一致（具体口径按行业修正）。

按悲观/基准/乐观情景记录需求、有效供给、价格、库存、资本开支与利润弹性。区分一次性补库存和持续终端消费。

## F. 价值增量、政策及产出

识别利润可能从哪里向哪里转移：技术升级、系统瓶颈、渠道权力、价格和产品组合。分析政策的法律状态、实施时间、适用对象、退出风险及企业具体影响，不把政策目标等同实际采购。

**输出表**：产品/客户矩阵；供需驱动树；市场规模及公式；行业关键指标看板；结构变化机会（受益/受损/前提/反证）；仍不确定的参数与数据来源。
