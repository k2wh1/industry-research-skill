# 证据、口径和研究质量规范

## 1. 证据优先级

1. **A/原始证据**：法定财报与公告、监管统计、官方定价、招投标与合同、公司投资者关系材料（涉及指引须注明是管理层说法）、正式论文、标准、原始数据库。
2. **B/高质量二手分析**：权威行业协会分析、具公开方法的数据库、业内机构研究、知名专业媒体经过核查的原始采访。
3. **C/线索材料**：新闻转述、论坛讨论、产业专家匿名观点、估算性第三方数据。

A级并不意味着天然正确；公司投资者材料有利益相关性，统计方法可能改变。可信度同时取决于来源是否合适、日期是否足够新、口径是否可复算、是否可独立验证。

## 2. 事实登记表

至少记录：

| 字段 | 解释 |
|---|---|
| claim_id | 例如 E001，与正文 `[E001]` 关联 |
| statement | 精确定义的事实/判断 |
| evidence_type | FACT / GUIDANCE / ASSUMPTION / INFERENCE |
| metric / value / unit | 量化口径与单位；文字事实可空数值 |
| geography / period | 区域与统计时间，注明财年/自然年 |
| source_org / document_title | 机构与文件名 |
| publish_date / accessed_date | 披露日与检索日，无法得知留空并标注 |
| url_or_file / page | 原始网址或可访问文件及页/表 |
| source_grade | A / B / C |
| confidence / limitations | 不确定性、与其他资料矛盾处 |

示例：某产品「产能」不等于「出货量」，某财年 Q1 不一定等于自然年第一季度；同一资料中出现不同单位时必须核对。财报数值应说明是否合并、是否经过调整、是否包含停业业务。

## 3. 搜索和交叉验证流程

- 将每项重要结论拆成可检索的原子命题，如「某公司 2026 财年 HBM 销售占比」「某地区 2025 年数据中心用电量」。
- 搜集原始来源，记录直接链接、页面/表格位置和发布日期；不能查看原文时注明「二次转引」。
- 对可比事实按「公司定义、产品范围、地理、期间、统计方法」五项匹配；不匹配时保留多个口径，不强行平均。
- 如果数据冲突，明确给出「来源 A=…、来源 B=…、可能差异原因=…、当前采用=…」；重大冲突不消除则暂缓量化结论。
- 对估算数据写出公式、参数和低中高区间；不得用假设数值冒充已披露事实。
- 查询研究基准日后发生的资料，除非用户明确要求更新，否则禁止混进历史基准日结论（防止前视偏差）。

## 4. 推断记录

关键投资推断至少标注：

`观察到的事实 → 经济传导机制 → 假设 → 可能的财务量化影响 → 反证 → 监控方式`。

示例（示意，不含实际行业结论）：

> 新建产能落地时间延后 `[E012]` → 未来两季有效供应低于计划（推断）→ 在终端需求不变时产品价格有支撑（假设）→ 毛利率可能上升，但客户库存下降或竞品放量可能抵消。跟踪产线良率、合同价、渠道库存。

## 5. 报告质量分层

- `可核验事实`：有可靠来源、明确日期和口径。
- `高置信推断`：有多条一致证据，机制合理，能被反证。
- `待验证假说`：机制存在但缺关键数据；须明确缺口。
- `不可判定`：数据不足以支持结论；不强制分类或评级。

**严禁**：编造来源链接、虚构财报数据、隐藏负面证据、把未经确认的媒体报道写成确定事实、把估算市场份额写成官方 CR4。
