# 11｜深度、完整性与信息保留协议（行业深度必读）

## 目的：把“研究完整”与“文字精炼”分开

正式行业深度不是速览或摘要。编辑可以删除无意义重复、调整标题、拆分表格，但不能凭主观判断删去一条独立的证据链、关键产品环节、重要公司、历史数据、反方证据或未解决的问题。**减少 AI 味 ≠ 缩短报告**；正文表述自然不意味着研究过程可以省略。

用户明确提出“行业全景、行业深度、系统全面、完整覆盖”时，使用 `industry_full` 深度层级；若只要求快速了解，则可选择 `industry_brief`。未说明深度但明确要求“深度研究报告”，默认 `industry_full`。

## 1. 完整性先行：先建覆盖登记表，后写正文

建立 `industry_coverage.csv`，可复制 `assets/industry-coverage-template.csv`。每个条目记录：研究问题/细分子行业、优先级、应达深度、证据编号、量化产出、状态、缺口与下一步。行业特殊维度要加行，而不是因模板中没有就不研究。

覆盖状态只能是：

- `complete`：完成关键问题、证据、经营机制及必要量化分析，结论可追溯；
- `partial`：有实质研究但仍缺关键环节；
- `missing`：未开展或证据不足；
- `not_applicable`：确实不适用，必须写清理由。

不能把“已写几句话”“列出公司名字”“出现了标题”视为 complete。正文写完后按照登记表逐行审计，未完成的内容标明为未完成/信息缺口，**不可把局部完成报告包装成完整行业深度**。

## 2. 全行业研究的建议覆盖骨架（根据行业取舍）

### A. 行业认知与产品结构

1. 定义、边界、术语、统计口径、发展历史、分类树（至少到足以反映不同商业模式的第二/三级）。
2. 每个**重要细分环节**的产品功能、技术/工艺步骤、替代品、性能与成本指标、成熟度和变化方向。
3. 终端场景、使用者、选型者、采购者、付款者、采购频率、合同方式及转换成本。
4. 产品定价方式、毛利来源、成本构成、单位经济与售后服务/更新收入。

### B. 市场规模、需求与供给

5. 历史 3–5 年规模及增速：总量与主要产品、客户、地区和工艺/应用细分，注明修订与统计差异。
6. 至少建立一种**可复算的自下而上模型**：终端数量 × 渗透/配置 × 价格/单位价值等，说明重复计算与范围差异。
7. 需求链：终端消耗/安装 → 客户预算 → 订单 → 交付 → 验收 → 收入，讨论时间滞后、库存与提前采购。
8. 供给：有效产能、利用率、良率、扩产时滞、库存、关键部件、交付/认证瓶颈；无法获得精确值时解释代理变量。
9. 价格、产品 mix、合同结构及供需错配如何传导到收入、利润、现金流；给出历史周期对照。

### C. 产业链、竞争与价值分配

10. 上中下游参与者及资金流，划分主要利润池；避免跨层级重复计算收入。
11. **逐重要细分市场**列领先者和主要挑战者，给产品定位、客户、份额及口径、竞争优劣势；分母不一致时不硬算 CR4/CR8。
12. 护城河：技术、专利、工艺验证、生态、切换成本、规模、供应链、品牌；分别验证持续性和可侵蚀性。
13. 同业多年可比的毛利率、营业利润率、研发强度、ROIC、Capex、FCF；披露不同财年/会计口径。
14. 议价权和利润迁移：哪些增量市场扩大、哪些产品受替代、谁承担新增投资与风险。

### D. 竞争者、政策与长期变化

15. 重点公司分层：全球龙头、区域龙头、国产/替代者、非上市关键技术或零部件公司；公司地图与可比指标不可只有名称。
16. 产业政策、出口/进口管制、合规、补贴和技术标准；政策目标、已生效规则和市场影响分开。
17. 新技术路径、路线之争、产业升级、需求/供给变化的短中长期机制；受益和受损条件。

### E. 投资与研究落地

18. 经营驱动模型或行业情景预测：关键变量、基准与上下行情景、公式和敏感性。
19. 可投资公司映射：业务暴露、利润弹性、资本效率和财务稳健性；**行业深度不强制每家估值**，涉及评级/目标价时必须追加公司估值模型。
20. 主要风险的发生机制、领先指标、历史参考、反证条件和资料渠道；给出后续跟踪表。
21. 数据来源、口径冲突、模型假设、尚待验证的问题和研究限度。

## 3. 细分行业“逐环节研究卡”

每个一级重要细分行业至少回答：

| 维度 | 必须回答的问题 |
|---|---|
| 产品与作用 | 产品具体做什么，在哪个工序/价值链，谁使用？ |
| 客户与商业模式 | 谁采购、谁付款、采购决策如何发生，收费结构是什么？ |
| 技术与替代 | 核心性能指标、领先工艺、替代路径及验证难度？ |
| 市场与增长 | 当前可核验规模、历史增速、增量来源、计量口径？ |
| 供需与竞争 | 有效供给、客户/供应商集中度、主要公司与份额？ |
| 财务与壁垒 | 价格/组合/毛利/研发/资本效率怎样决定利润？ |
| 前景与风险 | 未来 1–3 年变量、技术变化、最关键反证？ |
| 证据和缺口 | 原始资料、模型参数、尚未验证的环节？ |

**重要性分级**：核心环节应具备数据、经营机制和公司比较；次要环节可简写并解释取舍。不能对所有环节只给一两句话并宣称已覆盖。

## 4. 深度产出和篇幅——质量检查而非凑字数

经验性规划（A4、中文 10.5–11 pt，正常图表密度，附录可另计；不是强制字数下限）：

| 类型 | 规划范围 | 最重要的交付特征 |
|---|---|---|
| `industry_brief` 速览 | 3–8 页 | 只回答少数关键问题，明确精简范围 |
| `thematic` 专题 | 10–20 页 | 争议深挖，具备定量模型 |
| `industry_full` 全行业深度 | 25–50 页 | 核心细分环节逐项研究、供需模型、竞争与公司地图、附来源 |
| `industry_landscape` 大型全景 | 50–100+ 页 | 多层级产业树与跨子行业公司对照，允许分卷 |

页面数取决于图表与版式，不能作为证明完整性的唯一标准。**如果已研究证据只能支撑 7 页，应明确标注“阶段性研究/速览”，不要通过重复、虚构数据扩到 30 页。** 必要时将大型研究拆为“主报告＋细分行业分册＋数据附录”，并维护统一覆盖表。

## 5. 深度报告的建议工作顺序与阶段门槛

1. **覆盖规划**：输出分类树、覆盖表、核心争议、优先研究问题、关键数据需求。
2. **研究与核验**：按细分环节收集原始资料，建立证据账本和测算表；记录缺口及替代证据。
3. **分析建模**：完成行业规模模型、供需平衡/约束、竞争与资本回报、主要情景的因果传导。
4. **结构整理**：写 1–2 页摘要，但正文分章节充分解释，不把摘要代替正文。
5. **编辑但不删内容**：保留证据、模型、历史对比、公司地图、反方及关键假设；可移动至表/附录而非删除。
6. **覆盖审查**：逐行核对 `industry_coverage.csv`，列出完整、部分、缺失和不适用，明确实际交付级别。

### 进入成稿阶段之前至少满足

- 核心细分领域均已明确覆盖状态，主要业务环节不存在未披露的空白；
- 重要统计口径和时间范围已注明；至少一个核心市场或经营模型可复算；
- 公司及技术竞争不只凭综合营业利润率排名；
- 事实、假设、推断和未来情景已区分；
- 主要反证、风险与缺口透明可见。

如果任何门槛未满足，只能将文档标为“阶段性报告/待补全”，不可宣称“全行业深度完成”。

## 6. 改写现有报告的“内容守恒”协议

用户要求“去 AI 味”“语言润色”“排版”而未要求删减时：

1. 先读取原稿全文，生成章节与材料保留清单：独立论点、关键数据、公式、图表、公司、来源、反方和研究缺口；
2. 原则上**每个实质内容单元均应在修订版中有对应位置**，包括可能移到附录的内容；
3. 对事实错误或无法支持的结论，不应原样背书；可保留其研究问题，并写明“待证/需更正”，但不能悄悄删除；
4. 不因一段语言像 AI 就连同有用数字、论据一起删掉；通过改写因果链、拆句和增加上下文来处理；
5. 输出 `revision_coverage.md`：原文章节 → 新文位置 → 保留/更正/待核实/合并及理由；
6. 如确需删减内容，须获得用户明确的摘要/精简请求，或记录为不可信内容的更正，不能把精简稿叫“完整版”。

## 7. 针对半导体设备的特殊覆盖要求（示例）

研究全行业时，按需求和供应链实际情况选择光刻、刻蚀、CVD/PVD/ALD、清洗、CMP、量检测、离子注入、热处理、涂胶显影、测试、先进封装、关键零部件等，并逐项建立产品/工艺、市场、公司、壁垒及未来变化记录。应分清晶圆制造设备（WFE）与测试/封装的统计口径；研发路线、国产验证进度、厂商服务收入、客户资本开支之间的联系不能用一家公司的利润率代替分析。

不要假设每个设备环节都有可信全球份额或全部中国国产化率。找不到一致的来源时，标为数据缺口并保留验证计划；不得自动生成 CR4、国产化率、市场规模数字。
