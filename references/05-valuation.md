# 05｜市场预期、估值方法选择与风险收益

## A. 先问：市场价格隐含什么？

估值前识别：
- 当前可核实价格、币种、收盘时间、总股本/稀释股本、公司行动和净债务，**每项带日期**。
- 可用的分析师一致预期：提供商、截面日期、样本、财年口径及分歧程度。没有可靠数据时明确写「共识数据缺失」。
- 市场隐含假设：将当前企业价值作为约束，反向求解长期收入增长率、营业利润率或可持续 ROIC（一次只求解一个或少数有经济意义的变量），说明其余固定参数。
- `研究预测 − 一致预期` 和 `研究预测 − 市场隐含假设` 是两类不同的预期差，不可混用。

## B. 决定哪种估值适用

| 商业类型 | 推荐主工具 | 核心注意 |
|---|---|---|
| 现金流稳定的非金融公司 | FCFF DCF + EV/EBITDA 或 PE 交叉 | 营运资本、终值、资本成本、股数 |
| 高度周期制造/资源 | 正常化中周期 EV/EBITDA、PE 或资产价值 + 情景 DCF | 不拿周期顶点利润乘高倍数 |
| 银行 | PB-ROE、剩余收益、股息/资本回报框架 | 资本充足、信用损失、监管分红约束 |
| 保险 | 内含价值或适用精算/资本框架 | 合同负债、投资收益及会计口径 |
| 多元业务集团 | SOTP | 分部口径、净债务分配、双重计价 |
| 早期/持续亏损业务 | 单位经济、概率加权场景、长周期现金流 | 融资稀释、终值依赖、盈利转正条件 |

严禁对银行套用工业企业的 `FCFF/WACC − 净债务` 套路。相对估值只选可比商业模式、资本结构、成长与风险相近的样本；列剔除理由。

## C. FCFF DCF（适用于非金融企业）

`EV = Σ FCFF_t/(1+WACC)^t + [FCFF_n×(1+g)/(WACC−g)]/(1+WACC)^n`。

`权益价值 = EV − 净债务 − 优先股/少数股东权益（如相关且未计入） + 非经营性资产（如未包含）`。

`每股价值 = 权益价值 / 完全稀释股数`。

使用 `scripts/dcf.py` 计算教学或已核实输入时，明确脚本只处理 `EV − net_debt` 的简化桥接，其他非经营资产/少数股东等**需要使用者先进行相容调整**，不得漏算。FCFF 配 WACC，FCFE 配股权资本成本；不可混合。

输入所采用单位必须一致，如 `FCFF：百万美元；净债务：百万美元；股份：百万股 → 价格：美元/股`。WACC 必须大于终值永续增长率，且负的股权价值需要解释，而不是舍弃。

## D. 三角验证

1. 自己的基准经营预测 + 主估值。
2. 同期可比企业与历史周期/同阶段倍数的交叉验证（若存在合理可比）。
3. 反向 DCF：当前股价需要什么经营增长/利润率才说得通？
4. 敏感性：WACC × g；ASP × 销量；毛利率 × Capex；必要时估计终值占 EV 比重。
5. 价格与价值分开：基本面价值区间 ≠ 一定达到的交易价格，尤其在高波动与事件驱动行业。

## E. 投资研究结论门槛

给目标价至少需要可核实的基准价格与日期、最新股数、净债务/优先权、完整估值模型和清晰的 12 月或其他明确期限；注明概率不是客观频率。评级需附体系定义和基准指数/阈值，不要随意模拟某券商真实评级制度。无可靠行情或股本时给出价值驱动条件、潜在估值范围及缺口，不强行写具体目标价。

**输出**：估值方法选择理由、主要假设、价值区间、敏感性、反向隐含假设、共识比较、关键风险以及估值限制。
