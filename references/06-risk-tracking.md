# 06｜风险矩阵、反方分析与可证伪性

## A. 风险登记

对每条风险写明：

| 字段 | 内容 |
|---|---|
| 风险 | 什么事情可能发生；外部/内部/监管/技术/融资/估值 |
| 发生机制 | 通过什么路径影响量价、利润率、ROIC 或自由现金流 |
| 时间 | 近期/1–2 年/长期，不随意把长期风险等同近期催化剂 |
| 发生概率 | 若无客观分布，用定性高/中/低并阐明依据 |
| 影响 | 数量级或情景区间，避免无依据的精确概率 |
| 前置信号 | 领先于财报的可观察变量 |
| 数据来源 | 官方披露、行业统计、价格序列、渠道/采购数据 |
| 触发阈值 | 哪个区间变化会使假设失效或必须重估 |
| 缓释方式 | 公司或投资分析的应对原则，说明执行成本 |

## B. 最强反方观点

对 1–3 条核心投资论点写“Steelman”：
1. 看多最强证据是什么；反方能够提出的最有力解释是什么？
2. 哪条可观测事实最有区分度？预计何时出现？
3. 该证据出现时预测模型的哪些项要改变？
4. 出现了与自己相反的证据，是否愿意修改观点和评级？

避免「市场不及预期」「竞争加剧」这种没有变量、机制、阈值的空话。

## C. 催化剂与事件风险

催化剂 = 可能带来信息更新/预期修订的事件，不等于必然价格上涨；标明可能披露窗口、信息状态、哪项假设可能被验证以及潜在利空方向。对数据滞后做披露日与事件日区分。

**输出**：风险矩阵、领先指标监控表、验证/证伪条件、催化剂日历（只使用核实的日期）、研究置信度及未解不确定性。
